二、重新生成图表
--------------
如需重新生成或修改参数：

1. 安装依赖：
   pip install numpy matplotlib

2. 运行脚本：
   python3 reproduce_paper_figures.py

3. 查看生成的PNG文件

三、图表说明
----------
所有图表包含：
✓ HISS - 硬判决迭代移位求和 (不同Imax)
✓ SISS - 软判决迭代移位求和 (不同Imax)  
✓ CHISS - Chase+HISS组合 (不同η,l)
✓ CSISS - Chase+SISS组合 (不同η,l)
✓ BM - Berlekamp-Massey基准
✓ ASD - 自适应软判决解码
✓ MLUB/MLLB - ML界限

四、参数说明
----------
Imax: 最大迭代次数 (3, 5, 10, 20)
η: Chase测试向量数 (5, 10)
l: 输出列表大小 (1, 2, 4, 8)
